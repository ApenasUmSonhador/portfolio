# POM-012 - Navigation Philosophy

## Filosofia de Navegação

A navegação deve construir confiança de maneira progressiva.

Cada interação deve aumentar a compreensão do visitante sobre a capacidade técnica do desenvolvedor.

O usuário nunca deve se perguntar qual é o próximo passo ou onde encontrar determinada informação.

A estrutura do produto deve permitir diferentes níveis de exploração:

- visão geral da carreira;
- conhecimento técnico;
- projetos desenvolvidos;
- estudos de caso;
- documentação;
- implementação;
- repositórios públicos.

Cada nível deve aprofundar o anterior, formando uma narrativa contínua.
