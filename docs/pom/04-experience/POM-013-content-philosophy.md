# POM-013 - Content Philosophy

## Filosofia de Conteúdo

Todo conteúdo publicado deve possuir um propósito claro.

A plataforma não deve acumular informações apenas para aumentar volume ou frequência de atualização.

Cada projeto, artigo, experimento, certificação, resolução de problemas, livro registrado ou estudo publicado deve contribuir para demonstrar a evolução profissional, a capacidade analítica ou a forma de trabalhar do desenvolvedor.

Qualidade, relevância e contexto têm prioridade sobre quantidade.
