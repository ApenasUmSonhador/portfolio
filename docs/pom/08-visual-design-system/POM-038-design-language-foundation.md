# POM-038 - Design Language Foundation

## Fundamentos da Linguagem de Design

A base visual segue um modelo inspirado em plataformas modernas de desenvolvimento de software, priorizando:

- simplicidade estrutural
- hierarquia clara de informação
- uso funcional de espaço em branco
- tipografia como principal elemento de expressão
- baixa dependência de elementos gráficos decorativos

A interface deve parecer um produto de engenharia, não um site promocional.
