# POM-043 - Component System

## Sistema de Componentes

Componentes são tratados como blocos reutilizáveis de sistema.

### Princípios:

- consistência entre estados (hover, active, disabled)
- previsibilidade de comportamento
- ausência de variações desnecessárias
- foco em reutilização ao longo do sistema

Cada componente deve existir por necessidade funcional, não estética.
