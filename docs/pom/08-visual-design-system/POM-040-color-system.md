# POM-040 - Color System

## Color Strategy

A paleta de cores segue um modelo controlado:

- base neutra dominante (cinzas, branco, preto)
- uma cor primária de marca para destaque
- uso extremamente limitado de cores secundárias

### Princípio central:

Cor é um mecanismo de comunicação, não de decoração.
