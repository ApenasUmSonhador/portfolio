# POM-041 - Typography System

## Sistema de Tipografia

Tipografia é o principal vetor de identidade e clareza.

### Diretrizes:

- fontes modernas, sans-serif
- alta legibilidade em mobile
- hierarquia clara (títulos, subtítulos, corpo, metadata)
- variação controlada de peso e tamanho
- uso consistente de espaçamento vertical

A tipografia deve sustentar toda a hierarquia de informação.
