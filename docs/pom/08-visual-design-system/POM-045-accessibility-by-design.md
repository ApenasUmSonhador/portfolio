# POM-045 - Accessibility by Design

## Acessibilidade como parte do Design

A acessibilidade é parte do design, não uma camada adicional.

- contraste adequado em todos os contextos
- navegação por teclado suportada
- foco visível consistente
- legibilidade em diferentes tamanhos de tela
