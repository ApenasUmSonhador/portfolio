# POM-039 - Personal Brand Layer

## Camada de Marca Pessoal

Sobre a base neutra de design, existe uma camada de identidade pessoal sutil.

### Essa camada pode aparecer em:

- pequenos acentos de cor
- elementos de destaque (links, CTAs)
- padrões de ilustração ou ícones
- microinterações consistentes
- assinatura visual discreta em áreas estratégicas

### Restrições:

- não comprometer legibilidade
- não afetar hierarquia de informação
- não interferir na leitura técnica
- não dominar o layout

A identidade visual deve ser percebida, não dominante.
