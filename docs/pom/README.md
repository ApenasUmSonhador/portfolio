# Product Operating Model (POM)

## Objetivo

O Product Operating Model (POM) define a visão, estratégia, princípios e diretrizes do produto.

Ele representa a principal especificação funcional da Portfolio Platform e serve como referência para todas as decisões relacionadas ao produto.

O POM não descreve detalhes de implementação. Esses aspectos são tratados pelos documentos de arquitetura e pelas decisões registradas em ADRs.

---

## Estrutura

| Grupo | Descrição |
|--------|-----------|
| 00 - Governance | Informações gerais e governança do POM |
| 01 - Product Vision | Visão, objetivos e proposta de valor |
| 02 - Product Strategy | Posicionamento e estratégia do produto |
| 03 - Personas | Perfis dos usuários e suas necessidades |
| 04 - Experience | Experiência do usuário e princípios do produto |
| 05 - Information Architecture | Organização da informação |
| 06 - Features | Funcionalidades da plataforma |
| 07 - UX | Diretrizes de experiência |
| 08 - Visual Design | Princípios de identidade visual |

---

## Convenções

- Cada documento possui um identificador permanente (`POM-XXX`).
- Os identificadores nunca são reutilizados nem renumerados.
- Cada documento representa uma única decisão ou conceito do produto.
- As motivações históricas das decisões arquiteturais são registradas em ADRs.
