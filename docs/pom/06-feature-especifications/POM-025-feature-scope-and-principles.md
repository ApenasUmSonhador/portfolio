# POM-025 - Feature Scope & Principles

## Escopo Excluído (MVP)

As seguintes funcionalidades não fazem parte do escopo atual:

- CV Engine automatizado
- Blog independente
- System Map global interativo
- camada automatizada de métricas e proof layer

Essas funcionalidades podem ser reavaliadas em fases futuras.

---

## Princípios de Funcionalidade

- Funcionalidades devem reforçar evidência técnica
- Não devem existir features desconectadas da arquitetura de informação
- Complexidade só é adicionada quando justificada por valor real
- O sistema deve priorizar consistência estrutural sobre variedade funcional
