# POM-026 - UX Philosophy

## Filosofia de Experiência do Usuário

A experiência da plataforma deve ser baseada em uma combinação de **minimalismo funcional** e **profundidade progressiva de informação**.

A interface não deve competir com o conteúdo técnico. Em vez disso, deve atuar como um sistema de organização que reduz carga cognitiva e permite exploração eficiente de informação em diferentes níveis de profundidade.

A complexidade do sistema deve estar na estrutura de dados e não na interface visual.
