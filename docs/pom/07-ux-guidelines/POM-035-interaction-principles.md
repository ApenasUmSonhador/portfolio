# POM-035 - Interaction Principles

## Princípios de Interação

- interações devem ser previsíveis
- feedback deve ser imediato e claro
- transições devem ser suaves e funcionais
- nenhuma interação deve exigir aprendizado excessivo
- profundidade deve ser acessível sem fricção
