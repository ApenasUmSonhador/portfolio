# POM-036 - Performance as UX

## Performance como Experiência do Usuário

Performance é parte da experiência do usuário.

- carregamento rápido é requisito de UX
- transições devem ser leves
- componentes devem ser otimizados por padrão
- percepção de velocidade é tão importante quanto métricas reais
