# POM-032 - Consistency Model

## Consistency Rules

A interface deve manter consistência rígida entre:

- componentes visuais
- padrões de navegação
- comportamento de interação
- estrutura de páginas

Inconsistências visuais são tratadas como defeito de arquitetura, não de design pontual.
