# POM-030 - Progressive Disclosure

## Progressive Disclosure Pattern

Informação deve ser apresentada em camadas progressivas:

- Overview inicial sempre visível
- detalhes técnicos sob demanda
- expansão incremental de contexto
- ausência de sobrecarga inicial

O usuário nunca deve ser exposto ao nível máximo de complexidade sem intenção explícita.
