# POM-034 - Content First Design

## Design Centrado em Conteúdo

O conteúdo técnico é o elemento central da experiência.

O design deve:

- facilitar leitura
- estruturar informação complexa
- evitar distrações visuais
- reforçar clareza conceitual

Interface nunca deve competir com conteúdo técnico.
