# POM-027 - Mobile First Constraint

## Contexto

Toda decisão de UX deve considerar primeiro o contexto mobile.

### Implicações:

- hierarquia vertical como padrão
- navegação simplificada
- redução de densidade informacional
- componentes reutilizáveis e responsivos
- priorização de leitura sequencial
- eliminação de elementos decorativos desnecessários

O comportamento desktop é uma extensão, não o ponto de partida.
