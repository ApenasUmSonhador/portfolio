# POM-016 - Navigation Model

## Hierarquia Principal (Menu)

A navegação principal adota um modelo híbrido, combinando acessibilidade para recrutadores com profundidade técnica para perfis mais experientes.

- Home
- Work (Products)
- Engineering
- Learning
- About
- Resume
- Contact

Esta estrutura prioriza clareza sem comprometer a representação da arquitetura interna do sistema.
