# POM-018 - Navigation Principles

## Princípios de Navegação

- O sistema deve ser compreensível em poucos segundos.
- A navegação deve permitir exploração profunda sem perda de orientação.
- A complexidade técnica deve ser progressiva, nunca imediata.
- O usuário nunca deve ficar sem um próximo passo claro.
- A estrutura deve suportar leitura rápida e análise profunda simultaneamente.

## Home Page

A página inicial adota um modelo de dashboard orientado à engenharia.

Seu objetivo é permitir acesso direto e eficiente aos principais módulos da plataforma, sem dependência de narrativa introdutória.

A Home funciona como ponto de entrada estruturado para:

- Products
- Engineering
- Learning
- Career
- Resume

A experiência prioriza navegação direta e compreensão imediata da estrutura do sistema.
