# POM-017 - Content Depth Model

## Profundidade de Navegação

A plataforma suporta até o nível máximo de profundidade (Nível 4 — Engenharia Completa), permitindo exposição detalhada de aspectos técnicos como:

- arquitetura de software
- decisões técnicas (ADRs)
- pipelines de CI/CD
- métricas de performance
- testes e qualidade
- observabilidade
- evolução do sistema

Cada projeto pode operar em diferentes níveis de maturidade (nível 2 a nível 4), conforme sua complexidade e estágio de desenvolvimento.

---

## Acesso ao Conteúdo Técnico

A exposição do conteúdo técnico segue o modelo de progressive disclosure.

A informação é organizada em camadas progressivas:

- Overview
- Contexto
- Detalhamento técnico
- Deep dive (arquitetura, decisões, CI/CD, métricas)

O usuário decide o nível de profundidade desejado sem ser sobrecarregado inicialmente por complexidade técnica.

Esse modelo garante equilíbrio entre:

- clareza para visitantes gerais
- profundidade para perfis técnicos
- escalabilidade da documentação
