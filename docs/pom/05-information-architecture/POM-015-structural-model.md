# POM-015 - Structural Model

## Estrutura Mental do Produto

A plataforma é organizada segundo uma estrutura baseada em quatro pilares principais:

- Products
- Engineering
- Learning
- Career

Esta estrutura representa a visão primária do sistema e define como o conteúdo é categorizado internamente.

Adicionalmente, existe uma camada secundária baseada em habilidades técnicas (Frontend, Backend, DevOps, etc.), utilizada exclusivamente como mecanismo de navegação e indexação, sem interferir na estrutura conceitual principal.
